# Data

The dataset is provided by the **DataDNA** challenge and is not redistributed here.

Download the Sunrise Coffee Chain files from the challenge page and place them in this folder:

- `dim_store.csv` (60 rows)
- `dim_product.csv` (40 rows)
- `dim_date.csv` (730 rows)
- `fact_store_monthly_profitability.csv` (1,440 rows)
- `fact_daily_sales.csv` (10,000 rows)

Check the file names against the challenge download, as they may differ slightly. The challenge also ships a `DATA_DICTIONARY.md`; see [`../docs/data_notes.md`](../docs/data_notes.md) for where the real data differs from it.
